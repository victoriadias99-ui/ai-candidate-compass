# AI-Powered Applicant Tracking System (ATS)
This project is a custom-built Applicant Tracking System designed to automate and optimize candidate screening and ranking processes using Artificial Intelligence.

## Project info

**URL**: https://id-preview--8e82028a-3f6b-4493-9d5f-b2ac52f737e6.lovable.app/

## Key Features
- Candidate evaluation based on structured Google Forms data
- Google Sheets integration as primary data source
- Optional CV (PDF) analysis as secondary input
- AI-powered scoring and ranking system
- Configurable evaluation criteria and weights
- Bias-reduced, objective hiring recommendations

## Tech Stack
- Backend: FastAPI (Python)
- AI Engine: OpenAI API
- Data Source: Google Sheets API
- Frontend: React (or Next.js / Vite)
- Deployment: Render
- Version Control: GitHub

## Architecture Overview
Candidate data is collected via Google Forms and stored in Google Sheets.  
The system evaluates candidates primarily using structured form responses, complemented by CV analysis when available.
